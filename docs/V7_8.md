# V7.8 Provenance Verification

V7.8 extends the required merge-authorization gate so provenance is not only issued but verified before merge.

After GitHub creates the OIDC-backed attestation for the exact-head server-policy evidence, the workflow runs `gh attestation verify` against the repository identity. The required gate fails if the evidence digest, attestation, or repository provenance cannot be verified.

This closes the gap between producing an attestation and actually consuming it as a merge condition.
