# Chief-of-Staff V6.2 — Production Provider Smoke Gate

V6.2 turns the external model-provider requirement into an executable GitHub Actions gate.

## What this adds

- A real connectivity smoke test against the configured OpenAI-compatible provider.
- A deterministic test job that still validates the V6.1 provider/PEP behavior without secrets.
- A separate real-provider job wired to repository secrets:
  - `MODEL_API_KEY`
  - `MODEL_BASE_URL`
  - `MODEL_NAME`
- The smoke test asks the provider for a strict JSON response with zero file operations and fails on transport errors, invalid JSON, or unexpected operations.

## Production rule

A green deterministic job proves the adapter logic. A green `real-provider-smoke` with the three repository secrets proves that GitHub can actually reach and invoke the production provider. Until those secrets are configured, the job exits as `SKIPPED` rather than pretending the provider has been validated.

Secrets are never printed by the test.
