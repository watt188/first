# Chief-of-Staff V6.4 — Real Codegen E2E

V6.4 proves that a configured external model can produce a bounded code change which is then written through the V6.1 default-deny PEP, independently verified, and preserved as CI evidence.

Acceptance path:

1. GitHub Actions loads MODEL_API_KEY / MODEL_BASE_URL / MODEL_NAME from repository secrets.
2. The real provider receives a deterministic backend task.
3. Provider output is parsed as JSON operations.
4. The operation is restricted to `generated/runtime_status.py` and applied through PEP.
5. AST syntax, shape, banned-symbol, and functional checks run after the write.
6. The generated file and report are uploaded as the `v64-real-codegen-evidence` workflow artifact.
7. The PR may merge only after this credentialed job and all repository checks pass.

The generated file exists only as CI evidence; model output is not committed automatically. This keeps repository mutation inside the reviewed PR/merge boundary.
