# V8.4 Live Recovery Orchestrator

V8.4 turns an exact-head GitHub failure snapshot into one bounded recovery action.

It validates PR/head binding, validates every failed job, classifies each failure through V8.2, and delegates the mutation to the V8.3 recovery action bridge. A single retryable provider failure may rerun exactly one failed job within budget; a deterministic code/test or evidence defect may request autonomous rework; policy, permission, ambiguous, exhausted, or heterogeneous simultaneous failures escalate to a human.

The orchestrator never merges, bypasses the server Ruleset, or writes to `main`. Multi-failure retry is deliberately fail-closed because independent retries can race and obscure the authoritative PR head.
