# V8.4 Live Recovery Orchestrator

V8.4 turns an exact-head GitHub failure snapshot into one bounded recovery action.

It validates PR/head binding and failed-job identity, classifies each failure through V8.2, and delegates the mutation to the V8.3 recovery action bridge. One transient provider failure may rerun exactly one failed job within budget; deterministic code/test or evidence defects may request autonomous rework; stale heads, policy/permission failures, exhausted retries, ambiguous states, and heterogeneous simultaneous failures escalate instead of retrying.

The orchestrator never merges, bypasses the server Ruleset, or writes to `main`.
