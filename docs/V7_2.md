# V7.2 GitHub Delivery Bridge

V7.2 defines the bounded bridge between autonomous delivery evidence and GitHub mutations.

## Proven contract

The bridge validates one delivery specification and an in-memory text-file bundle before any mutation. It then enforces exactly this order:

1. create branch from the declared immutable base SHA;
2. commit the declared files to that branch;
3. require a valid 40-character commit head SHA;
4. create a pull request whose body embeds the base SHA, returned head SHA, and SHA-256/byte manifest for every delivered file.

Unsafe paths, invalid base SHAs, branch mismatches, invalid commit heads, and PR head mismatches fail closed.

## Boundary

The bridge is transport-agnostic. Network mutation is delegated to a concrete GitHub gateway. The V7.2 CI gate proves the mutation protocol using a deterministic fake gateway; it does not claim that CI itself created a live GitHub PR. Live branch/commit/PR mutation remains an integration-layer responsibility and repository verification gates remain authoritative before merge.

This version does not auto-merge and does not bypass branch protection or repository checks.
