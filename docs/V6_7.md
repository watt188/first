# V6.7 Provider Resilience

V6.7 hardens the OpenAI-compatible model provider without changing its public V6.1 interface.

## Guarantees

- Bounded retries for transient HTTP failures: 408, 409, 425, 429, 500, 502, 503, 504.
- Retries for network/timeout failures and provider protocol decoding failures.
- Empty final model responses are treated as transient and retried.
- Exponential backoff with bounded jitter.
- Configurable request timeout and maximum attempts through environment variables.
- Non-retryable errors such as 401 fail immediately.
- Consecutive failed invocations open an in-process circuit breaker; calls fail fast until cooldown expires.
- Health snapshot exposes configuration/circuit state without exposing secrets.
- Error strings are sanitized categories rather than raw exception bodies.
- `reasoning_content` is never exposed wholesale; only explicitly delimited final artifacts may be recovered.

## Environment controls

- `MODEL_MAX_ATTEMPTS` default 3, bounded 1..6.
- `MODEL_TIMEOUT_SECONDS` default 30, bounded 1..120.
- `MODEL_CIRCUIT_FAILURE_THRESHOLD` default 3, bounded 1..20.
- `MODEL_CIRCUIT_COOLDOWN_SECONDS` default 30, bounded 1..300.

## Verification

`tests/test_provider_resilience_v67.py` deterministically verifies retry, backoff, empty-response recovery, immediate 401 failure, timeout sanitization, circuit-open behavior, and reasoning-trace containment without calling an external model provider.
