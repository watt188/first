# V8.1 Protected Autonomous Delivery

V8.1 composes the existing production guarantees into one bounded delivery controller:

1. autonomous generation produces PR-ready outputs and sealed evidence;
2. evidence must bind to the exact requested base SHA;
3. the live GitHub server-policy snapshot must satisfy the production ruleset contract;
4. only verified generated text outputs are handed to the V7.2 branch/commit/PR bridge;
5. the controller opens a pull request but never merges or bypasses GitHub;
6. the base-trusted V8.0 merge root and server-side Ruleset remain final merge authority.

The already-required `ci` context now includes deterministic V8.1 tests, so policy, evidence, path, or controller regressions block merge.
