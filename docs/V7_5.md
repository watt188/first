# V7.5 Merge Authorization

V7.5 adds a fail-closed merge authorization contract between verified delivery evidence and the actual GitHub merge mutation.

Authorization requires all of the following at the same time:

- the PR is not draft and GitHub reports it mergeable;
- the observed head SHA still equals the expected immutable head SHA;
- evidence is PASSED and bound to that exact head SHA;
- every declared required check exists and has conclusion `success`.

A head move, stale evidence, missing check, failed check, draft PR, or unmergeable PR denies authorization.

## Boundary

The V7.5 module does not itself call GitHub's merge API. It produces a deterministic authorization decision for the integration layer. The integration layer must still submit the expected head SHA to GitHub when performing a merge so that a race after authorization is rejected by GitHub as well.
