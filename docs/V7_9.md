# V7.9 Trusted Merge Root Bootstrap

V7.9 bootstraps the merge-authorization workflow into a base-trusted `pull_request_target` execution path.

The workflow temporarily listens to both `pull_request` and `pull_request_target` so this migration can pass the existing protected-branch contract. Its job is explicitly named `v75-merge-authorization`, matching the server-required status context.

After this bootstrap is merged, the next hardening step can remove the head-controlled `pull_request` trigger and the mirror copy of the `v75-merge-authorization` context. The authoritative merge-root check will then execute from the protected base branch definition and cannot be changed by the pull request it is evaluating.
