# V7.9 Protected Autonomous Delivery

V7.9 composes the previously separate production guarantees into one bounded delivery controller:

1. autonomous generation produces PR-ready outputs and V6.9-sealed evidence;
2. the evidence must bind to the exact requested base SHA;
3. the live GitHub server-policy snapshot must satisfy the V7.6 main-production-gate contract;
4. only verified generated text outputs are handed to the V7.2 branch/commit/PR bridge;
5. the controller opens a pull request but never merges or bypasses GitHub;
6. GitHub Rulesets and the required CI contexts remain the final merge authority.

The required `ci` check now includes deterministic V7.9 tests, so policy/evidence/controller regressions block merge under the server-side ruleset.

V7.9 does not grant unattended merge authority. It deliberately stops at a protected PR opening boundary.
