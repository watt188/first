# Chief-of-Staff V6.3 — Strict Production Provider Gate

V6.3 removes the last false-positive condition from provider validation.

## Production rule

The strict provider job MUST fail when any of these are missing:

- `MODEL_API_KEY`
- `MODEL_BASE_URL`
- `MODEL_NAME`

It also fails on provider transport errors, invalid JSON, or unexpected operations.

A green `v63-strict-provider` job therefore means GitHub Actions actually reached the configured production model and received a valid constrained response. Missing provider configuration is no longer reported as success or skipped validation.

Secret values are never printed.
