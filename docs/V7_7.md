# V7.7 Artifact Provenance

V7.7 upgrades the required `v75-merge-authorization` gate from hash-only policy evidence to GitHub-attested provenance.

For every pull request, the required gate now:

1. validates the live `main-production-gate` Ruleset;
2. writes an exact-head server-policy evidence JSON file;
3. requests an OIDC-backed GitHub artifact attestation for that evidence;
4. uploads the evidence artifact only after the attestation step succeeds.

The merge gate therefore fails if GitHub cannot issue provenance for the policy evidence. This adds cryptographic workflow identity and commit provenance on top of the existing V6.9 chained SHA-256 integrity model.

Boundary: GitHub-hosted attestation is stronger than a local hash chain but is still rooted in GitHub's attestation and OIDC trust infrastructure rather than a user-controlled hardware key.
