# V10.8 Live GitHub PR Head Resolver

V10.8 provides the concrete authoritative PR-head source required by V10.7. `GitHubPRHeadResolverV108` performs a fail-closed HTTPS GET against GitHub's pull-request API and returns only a validated lowercase 40-character head SHA.

Security properties:

- Repository identity is validated before use.
- HTTPS is mandatory for the configured API base.
- Optional bearer credentials are supplied at runtime and are never intentionally persisted or logged by the resolver.
- Network, HTTP, timeout, malformed JSON and malformed head responses fail closed.
- V10.7 remains responsible for comparing the caller's expected head against this authoritative value and for overwriting caller-supplied `current_head_sha` before recovery delegation.

This version does not prove GitHub's remote service itself is uncompromised, does not provide distributed trust or consensus, and does not add new exactly-once guarantees for downstream physical side effects.
