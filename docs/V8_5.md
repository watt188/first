# V8.5 Recovery Evidence Ledger

V8.5 adds an append-only, exact-head-bound evidence ledger for autonomous recovery actions.

Each accepted recovery receipt records the PR number, exact head SHA, failed workflow/job, recovery category/action, monotonic attempt number, previous event hash and current event hash. Verification fails closed on stale head bindings, tampering, chain breaks, non-monotonic retry history or unaccepted receipts.

The ledger records recovery evidence only. It does not merge, bypass GitHub Rulesets, alter required checks or write directly to `main`. V8.5 deterministic tests run inside the already-required `ci` context.
