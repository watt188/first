# V8.8 Recovery Replay Guard

V8.8 closes the duplicate-mutation gap in protected recovery sessions.

Before a recovery action can execute, the guard verifies the V8.5 evidence chain, rebinds the intent to the exact PR head, derives a deterministic SHA256 idempotency key from PR/head/workflow/job/action/attempt, and rejects any logical action already present in accepted recovery evidence. Attempts for the same job must advance monotonically.

The guard is fail-closed on stale heads, tampered evidence, duplicate replay, stale attempts, and invalid recovery identity. It does not rerun jobs, request rework, merge pull requests, bypass repository rules, change required checks, or write to main.

Deterministic V8.8 tests are bound into the existing required `ci` context.
