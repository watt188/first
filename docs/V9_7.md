# V9.7 Recovery Transaction Reconciler

V9.7 closes the remaining post-mutation crash windows in V9.6 without replaying an already accepted external recovery action.

## Flow

1. Bind to the exact PR head and derive the V8.8 replay key.
2. Require a durable V9.3 journal record for that exact recovery identity.
3. PREPARED remains unresolved and fails closed; ABORTED fails closed.
4. COMMITTED with a stable receipt is treated as proof that the logical external recovery was accepted.
5. If matching V8.5 evidence is missing, append it once and persist with CAS.
6. If matching evidence is already present, do not append it again.
7. Clear a remaining lease only when it belongs to this worker or has expired.
8. Every state mutation is exact-head and compare-and-swap protected.

## Crash windows covered

- external mutation committed, process crashes before evidence CAS;
- evidence CAS succeeds, process crashes before lease release;
- a later worker encounters an expired lease after a proven committed action.

## Fail-closed boundaries

V9.7 will not infer success from a PREPARED journal record, will not clear an active foreign lease, and will not replay the external mutation. A CAS conflict remains a hard stop requiring another fresh reconciliation pass.

This preserves V9.5/V9.6's boundary: exactly-once physical side effects still depend on downstream durable idempotency semantics.
