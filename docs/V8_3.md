# V8.3 Recovery Action Bridge

V8.3 turns the V8.2 recovery decision into a bounded executable action contract.

The bridge is exact-head bound and fail-closed. It can only:

- rerun one failed job when V8.2 classifies the failure as retryable and the retry budget is not exhausted;
- request autonomous rework for deterministic code/test or evidence defects;
- escalate policy drift, permission failures, exhausted retries, and ambiguous failures to a human.

It never merges a pull request, bypasses the GitHub Ruleset, writes to `main`, or accepts an action receipt that does not explicitly confirm acceptance.

The deterministic V8.3 tests are executed inside the already-required `ci` context, so regressions in stale-head protection, retry budget enforcement, rework routing, or fail-closed receipts block merge.
