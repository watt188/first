# V6.5 Chief of Staff Multi-Agent Delivery

V6.5 proves a bounded real multi-agent engineering loop instead of a single model-generated function.

Pipeline:

1. Chief of Staff asks a real planner model to decompose one feature goal into backend and test tasks.
2. A backend specialist generates implementation code as structured JSON.
3. A test specialist independently generates executable tests as structured JSON.
4. A reviewer specialist evaluates both artifacts and must explicitly approve them.
5. Only exact allowlisted paths are written through UnifiedPEPV61.
6. Acceptance parses both files, rejects dangerous symbols, imports the generated implementation/tests, executes specialist tests, and performs independent contract assertions.
7. GitHub Actions uploads generated implementation, generated tests, and JSON evidence.

V6.5 is intentionally bounded: specialists cannot choose arbitrary paths, cannot directly commit model output, and cannot bypass the PR/CI/merge boundary.
