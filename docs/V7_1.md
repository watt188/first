# V7.1 Autonomous Delivery

V7.1 turns the converged V7.0 runtime into a bounded autonomous delivery loop.

## Contract

Input: one engineering goal.

Pipeline:

1. Chief of Staff receives the goal.
2. Specialist execution produces implementation and tests.
3. PEP governs writes.
4. Verification executes before delivery is declared ready.
5. Evidence is sealed with V6.9 integrity binding to the exact source head SHA.
6. The runtime emits a PR-ready delivery report.

## Commands

```bash
python -m autonomous_delivery.v71 "<goal>"
```

## Evidence

The runtime produces:

- `artifacts/v71-autonomous-delivery.json`
- `artifacts/v71-evidence-manifest.json`
- `generated/feature_v65.py`
- `generated/test_feature_v65.py`

The manifest is verified against the exact PR head SHA in GitHub Actions.

## Boundary

V7.1 automates delivery preparation and evidence generation. It does not itself call the GitHub API to create or merge a pull request. PR mutation remains an external side effect owned by the GitHub integration layer and merge still requires passing repository gates.
