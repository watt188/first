# V9.1 SQLite Recovery State Store

V9.1 provides the first durable implementation of the V9.0 recovery state CAS contract using Python's standard SQLite engine.

## Guarantees

- state survives process restart and store re-open;
- writes execute under `BEGIN IMMEDIATE` transactions;
- compare-and-swap validates both generation and state hash;
- stale workers cannot overwrite newer recovery state;
- persisted state is re-read and verified after commit;
- embedded V8.5 evidence and V8.9 leases are verified on every read/write;
- SQLite WAL and `synchronous=FULL` are enabled;
- deterministic concurrency/persistence/tamper tests are bound into required `ci`.

This is a durable single-node store, not a distributed consensus system. It does not grant merge authority, bypass the repository Ruleset, change required checks, or write to `main` directly.
