# V9.0 Durable Recovery State

V9.0 closes the persistence gap left by the V8.9 lease guard by defining a compare-and-swap state contract for recovery leases and evidence.

## Guarantees

- recovery state is bound to one PR and exact head SHA;
- each state has a monotonic generation;
- each state is sealed with a deterministic SHA256 hash;
- V8.5 evidence ledgers are verified before state acceptance;
- V8.9 leases are verified before state acceptance;
- stale generations cannot overwrite newer state;
- stale hashes cannot overwrite newer state;
- cross-head state is isolated;
- deterministic tests are bound into the existing required `ci` context.

`InMemoryRecoveryStateStoreV90` is the deterministic reference transport. Production transports must implement the same read + compare-and-swap contract using a durable backend. V9.0 does not merge pull requests, bypass the server Ruleset, change required checks, or write to `main` directly.
