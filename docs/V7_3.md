# V7.3 Live GitHub Mutation

V7.3 proves that the delivery path is not only modeled through a fake gateway: the integration layer performs a real GitHub branch/commit/pull-request mutation, while CI validates the resulting pull-request event and seals a receipt bound to the exact live head SHA.

## Proven path

1. create a real release branch from immutable main SHA;
2. commit V7.3 code to that branch through the GitHub integration;
3. create a real pull request against main;
4. validate repository, PR number, base SHA, head SHA, and bounded release branch from the actual pull_request event;
5. seal the live receipt with V6.9 evidence integrity using the exact PR head SHA;
6. verify the sealed receipt before upload.

The dedicated workflow uploads `v73-live-github-mutation-evidence` containing the live receipt and its commit-bound manifest.

## Boundary

This proves live GitHub mutation through the authorized integration path. It does not auto-merge, bypass branch protection, or claim hardware-backed attestation. Repository gates remain authoritative before merge.
