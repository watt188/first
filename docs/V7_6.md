# V7.6 Server Policy Attestation

V7.6 binds the existing required `v75-merge-authorization` status check to the live GitHub Ruleset protecting `main`.

The gate fetches the repository Ruleset at runtime and fails closed unless all of the following remain true:

- `main-production-gate` is active;
- only `refs/heads/main` is targeted;
- deletion and non-fast-forward updates are restricted;
- pull requests are required;
- no bypass actors exist;
- strict required-status-check synchronization is enabled;
- all 17 declared production checks remain required.

Because `v75-merge-authorization` itself is a server-required status check, weakening the live Ruleset causes the merge gate to fail on subsequent pull requests rather than silently drifting from the expected production policy.
