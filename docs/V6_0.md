# Chief-of-Staff V6.0 — Production Baseline

V6.0 freezes the verified production-facing core instead of adding another parallel execution architecture.

Frozen surface: `run / verify / release / recover / status`.

This production slice adds an immutable Production Profile, an explicit secret boundary, startup preflight/health primitives, and a machine-evaluable production acceptance standard. Production release remains intentionally blocked until the external model provider and GitHub repository integration are both available.

The repository workflow compiles the V6.0 production baseline and runs its standard-library unit tests on every pull request to `main`.
